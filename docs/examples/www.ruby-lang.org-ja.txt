# Ruby Programming Language

> The Japanese-language edition of the official Ruby programming language website, for programmers who want to download and install Ruby, read documentation, find gems, follow core development, report security issues, and get release and security news.

## Docs

- [ドキュメント](https://www.ruby-lang.org/ja/documentation/): A Japanese Ruby documentation hub linking to the reference manual, a 20-minute quickstart, language guides, English references, old manual versions, and editor tools.
- [Rubyコア開発](https://www.ruby-lang.org/ja/dev/): Describes resources for following Ruby's core development: wiki, mailing lists, issue tracker, source snapshots, and how to contribute.
- [Rubyのインストール](https://www.ruby-lang.org/ja/documentation/installation/): Explains the many ways to install Ruby, covering package managers, installers, version managers and building from source, with commands for each.

## Guides

- [ライブラリ](https://www.ruby-lang.org/ja/libraries/): Explains how Ruby third-party libraries are distributed as gems, how to search, install and list them with the gem command, and points to RubyGems, GitHub and The Ruby Toolbox.

## Pages

- [セキュリティ](https://www.ruby-lang.org/ja/security/): Explains how to report Ruby security issues via HackerOne or email, and lists past translated security advisories.

## Optional

- [コミュニティ](https://www.ruby-lang.org/ja/community/): Lists Ruby community groups, IRC channels, Slack, mailing lists, newsgroups and conferences, with links and short descriptions of each.
- [最近のニュース](https://www.ruby-lang.org/ja/news/): A Japanese-language list of recent Ruby news posts, including release announcements, security advisories and conference registration notices, each with a short excerpt and date.
- [このウェブサイトについて](https://www.ruby-lang.org/ja/about/website/): Describes how the Ruby website is built with Jekyll, where its source is hosted, who designed it, and how to report issues or contribute.
- [Ruby のロゴについて](https://www.ruby-lang.org/ja/about/logo/): Explains the copyright and Creative Commons license terms for the Ruby logo and links to a downloadable logo kit in several formats.
