# Tailscale

> Tailscale is a connectivity platform built on WireGuard that creates private encrypted networks (tailnets) with identity-based, zero trust access to devices and infrastructure. It is for developers, IT and security teams, and homelab users, and the site offers documentation, downloads,…

## Docs

- [Docs · Tailscale Docs](https://tailscale.com/docs.md): The Tailscale documentation hub, linking to getting-started material, tailnet management, features, integrations, and technical reference.

## Guides

- [Bring Tailscale to Work](https://tailscale.com/bring-tailscale-to-work): A form for teams to request help rolling out Tailscale at work, with rollout guidance on grants, ACLs, SSO and SSH.
- [DevOps Learning Library](https://tailscale.com/learn): An index of Tailscale networking learning articles, covering VPNs, zero trust, AI infrastructure and data security topics, with short summaries of each.
- [Tailscale: How it works](https://tailscale.com/how-it-works): A long 2020 blog article by Tailscale's Avery Pennarun explaining the architecture of the Tailscale system, covering WireGuard, coordination, NAT traversal, DERP relays, and ACLs.
- [Using Tailscale in FedRAMP Moderate Environments](https://tailscale.com/resources/fedramp): Explains how Tailscale can fit within FedRAMP Moderate environments, covering security posture, boundary definition, system categorization, and FIPS compliance context, with an offer of help.

## Product

- [Download](https://tailscale.com/download): Download page offering the Tailscale macOS app, with system requirements, a Mac App Store link, and a link to install instructions.
- [WireGuard® for Enterprise](https://tailscale.com/wireguard-vpn): Marketing page describing Tailscale's managed WireGuard VPN for enterprises, covering key management, identity-aware access, access policies, and log streaming.
- [Features](https://tailscale.com/features): A catalogue of Tailscale's 40 features grouped by area, including access control, monitoring, SSH, networking, posture management and user management, each linking to documentation.
- [Integrations for Almost Anything](https://tailscale.com/integrations): A categorized directory of Tailscale integrations with identity providers, operating systems, cloud providers, IaC tools, and other third-party products, each linking to setup docs.
- [Homelab Networking Setup | Securely Connect Devices & Services with Tailscale](https://tailscale.com/use-cases/homelab): Marketing page describing how Tailscale creates a private encrypted mesh network to connect homelab devices from anywhere without exposed ports.
- [Secure Infrastructure Access with Zero Trust](https://tailscale.com/use-cases/infrastructure-access): Marketing page describing Tailscale's zero trust infrastructure access for databases, Kubernetes clusters, VMs and containers with least-privilege controls.
- [Manage SSH Keys Securely with Tailscale](https://tailscale.com/tailscale-ssh): Product page describing Tailscale SSH features such as automated key management, identity provider integration, browser-based SSH console, and pricing tiers.
