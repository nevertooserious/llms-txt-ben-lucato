# Tailscale

> Tailscale is a WireGuard-based connectivity platform that creates private, identity-based Zero Trust networks (tailnets) connecting devices, servers and cloud resources. It is for developers, IT and security teams, and homelab users, to set up secure remote access, SSH and infrastructure access.
