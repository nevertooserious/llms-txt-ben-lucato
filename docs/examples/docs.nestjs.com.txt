# NestJS

> NestJS documentation for Nest, a TypeScript-first framework for building server-side Node.js applications. It covers core concepts such as controllers, providers and modules, plus the CLI, first-party packages, database integrations, security and deployment.

- Nest runs on Express by default and can be configured to use Fastify or Node's own node:http through adapters.
- Nest is built with TypeScript but also supports plain JavaScript, including a JavaScript starter project.
- The site says to check Nest's first-party packages, such as authentication, mail, file storage, webhooks and queues, before adding another library.

## Docs

- [Controllers](https://docs.nestjs.com/controllers.md): Explains how NestJS controllers handle requests and responses, covering routing, decorators, status codes, redirects, route parameters and request payloads.
- [Providers](https://docs.nestjs.com/providers.md): Explains Nest providers: injectable classes, dependency injection, scopes, optional and property injection, custom providers, and module registration with examples.
- [Modules](https://docs.nestjs.com/modules.md): Explains NestJS modules: the @Module() decorator, root and feature modules, exports, sharing, global and dynamic modules, with code examples.
- [Middleware](https://docs.nestjs.com/middleware.md): Explains NestJS middleware: writing class and functional middleware, applying it to routes, exclusions, global middleware, and error handling.
- [Exception filters](https://docs.nestjs.com/exception-filters.md): Explains NestJS's built-in exceptions layer, HttpException usage, built-in exception classes, and how to write, bind and scope custom exception filters.
- [Pipes](https://docs.nestjs.com/pipes.md): Explains what NestJS pipes are, their transformation and validation use cases, built-in pipes, and how to bind and build custom pipes.
- [Guards](https://docs.nestjs.com/guards.md): Explains NestJS guards, which decide at runtime whether a request reaches a route handler, with examples of authorization, role-based access and binding.
- [Interceptors](https://docs.nestjs.com/interceptors.md): Explains NestJS interceptors: how they wrap handler execution, bind via decorators or globally, and map responses, exceptions, caching and timeouts.
- [Custom decorators](https://docs.nestjs.com/custom-decorators.md): Explains how to create custom param decorators in NestJS, including passing data, pipes, and composing decorators with applyDecorators.
- [Standalone applications](https://docs.nestjs.com/standalone-applications.md): Explains how to create and use a NestJS standalone application context to retrieve providers outside of web or microservice listeners.
- [Custom providers](https://docs.nestjs.com/fundamentals/custom-providers.md): Explains Nest's dependency injection system and custom provider types, including value, class, factory, alias providers and exporting them.
- [Async providers](https://docs.nestjs.com/fundamentals/async-providers.md): Explains how to create asynchronous providers in NestJS using async factories with useFactory and how to inject them by token.
- [Dynamic modules](https://docs.nestjs.com/fundamentals/dynamic-modules.md): Explains NestJS dynamic modules: how to build them with register methods, inject options, and use ConfigurableModuleBuilder for async configuration.
- [Injection scopes](https://docs.nestjs.com/fundamentals/injection-scopes.md): Explains provider and controller injection scopes (singleton, request, transient), scope hierarchy, request and inquirer providers, performance, and durable providers for multi-tenant apps.
- [Circular dependency](https://docs.nestjs.com/fundamentals/circular-dependency.md): Explains circular dependencies in NestJS and how to resolve them using forwardRef, the ModuleRef class, and module forward references.

## API

- [GraphQL + TypeScript - Mapped types](https://docs.nestjs.com/graphql/mapped-types.md): Explains NestJS GraphQL mapped type utilities (PartialType, PickType, OmitType, IntersectionType) for code-first input types, with examples and a custom helper.
- [Usage - CLI](https://docs.nestjs.com/cli/usages.md): Reference for the NestJS CLI commands, covering nest new, generate, build, start, add, upgrade and deploy with their arguments and options.
- [Decorators - OpenAPI](https://docs.nestjs.com/openapi/decorators.md): Lists the OpenAPI decorators exported by NestJS with the levels (method, controller, model) where each can be applied.

## Guides

- [First steps](https://docs.nestjs.com/first-steps.md): Introduces core Nest fundamentals: installing the CLI, creating a project, bootstrapping main.ts, choosing platform adapters, running, linting, and coding agent setup.
- [Deployment](https://docs.nestjs.com/deployment.md): Guide covering NestJS production deployment: building, NODE_ENV, running, health checks, logging, scaling, Docker, and the Mau deployment platform.
- [Migration guide - FAQ](https://docs.nestjs.com/migration-guide.md): Guide for migrating a NestJS project from version 11 to version 12, covering packages, Node.js requirements, ESM, and breaking changes.
- [Internationalization](https://docs.nestjs.com/application/i18n.md): Explains how @nestjs/i18n translates responses, exceptions, validation messages and GraphQL fields per request, with catalog setup and examples.
- [File storage](https://docs.nestjs.com/application/file-storage.md): Tutorial on @nestjs/storage covering named disks, public and signed URLs, streamed uploads with type and size checks, and S3 or R2 configuration.
- [Drizzle](https://docs.nestjs.com/data/drizzle.md): Guide to using Drizzle ORM with NestJS via @nestjs/drizzle: schema, module registration, queries, relations, transactions, migrations, testing and configuration.
- [Prisma](https://docs.nestjs.com/data/prisma.md): A NestJS guide to integrating Prisma ORM: installation, schema and migrations, PrismaService and module setup, querying, transactions and testing.
- [Authentication](https://docs.nestjs.com/security/authentication.md): Tutorial and reference for the @nestjs/authentication package, covering sign-in features, setup of users, sessions and sign-up with sign-in endpoints.
- [Authorization](https://docs.nestjs.com/security/authorization.md): Tutorial on adding policy-based authorization to a NestJS API, with a sample cat food store, product policies, and guard setup.
- [MVC](https://docs.nestjs.com/http/mvc.md): Explains how to build an MVC app in NestJS with Express or Fastify, covering template engines, views, layouts and dynamic rendering.
- [Observability - Choosing an APM for NestJS](https://docs.nestjs.com/observability/choosing-an-apm.md): Compares APM tools for NestJS applications, covering setup, what each sees of Nest, and when to choose each one.
- [Resilience](https://docs.nestjs.com/reliability/resilience.md): Explains the @nestjs/resilience package: retries, timeouts, circuit breakers, bulkheads and fallbacks as decorators, with a tutorial hardening a shipping carrier integration.
- [Idempotency keys](https://docs.nestjs.com/reliability/idempotency.md): Guide to making NestJS payment routes, GraphQL mutations and message handlers safe to retry using Idempotency-Key headers and the @nestjs/idempotency package.
- [Transactional outbox](https://docs.nestjs.com/reliability/outbox.md): A tutorial on the transactional outbox in @nestjs/outbox, covering dual-write risk, storage setup, migrations, and registering the outbox on PostgreSQL with Drizzle.
- [Durable workflows](https://docs.nestjs.com/reliability/workflows.md): Tutorial for @nestjs/workflows explaining durable multi-step processes, their persistence in a database, and how they compare with queues and sagas.
