# Bun

> Bun is a JavaScript and TypeScript runtime and toolkit that ships a package manager, test runner, bundler, type checker and formatter in one binary. This site provides its documentation, guides, API reference and blog for developers building and running JavaScript applications.

- Bun's install and test commands can be used in existing Node.js projects without switching the runtime to Bun.
- Bun runs on JavaScriptCore and aims to support Node.js APIs and node_modules as-is.

## API

- [File System Router](https://bun.sh/docs/runtime/file-system-router.md): Documents Bun's FileSystemRouter API for resolving Next.js-style pages directory routes, with usage examples and a reference interface.
- [Server](https://bun.sh/docs/runtime/http/server.md): Explains how to run an HTTP server with Bun.serve, covering routes, ports, TLS protocols, timeouts, lifecycle methods, and a reference of server options.
- [WebSockets](https://bun.sh/docs/runtime/http/websockets.md): Explains Bun.serve server-side and client-side WebSocket APIs, including handlers, pub/sub, compression, backpressure, closing, timeouts and errors.
- [SQL](https://bun.sh/docs/runtime/sql.md): Documents Bun's built-in SQL client for PostgreSQL, MySQL, MariaDB and SQLite, covering connections, queries, parameters, results and transforms.
- [Redis](https://bun.sh/docs/runtime/redis.md): Documentation for Bun's native Redis client, covering connection setup, commands, pub/sub, options, error codes and usage examples.
- [S3](https://bun.sh/docs/runtime/s3.md): Explains Bun's S3 API for reading, writing, presigning and deleting objects in S3-compatible storage, with client setup, credentials and error codes.
- [Hashing](https://bun.sh/docs/runtime/hashing.md): Documents Bun's password hashing and verification APIs, non-cryptographic Bun.hash functions, and Bun.CryptoHasher for digests and HMAC.
- [Cookies](https://bun.sh/docs/runtime/cookies.md): Documents Bun's native Cookie and CookieMap APIs for parsing, generating and manipulating HTTP cookies, with methods, properties and types.
- [Fetch](https://bun.sh/docs/runtime/networking/fetch.md): Documents Bun's fetch API for sending HTTP requests, including proxies, headers, TLS, streaming, protocols, performance options and debugging.
- [File I/O](https://bun.sh/docs/runtime/file-io.md): Documents Bun's Bun.file and Bun.write APIs for reading, writing, and deleting files, incremental FileSink writing, directory operations, and a reference.
- [Spawn](https://bun.sh/docs/runtime/child-process.md): Explains how to spawn and control child processes with Bun.spawn and Bun.spawnSync, covering streams, exit handling, IPC, terminals, and an API reference.
