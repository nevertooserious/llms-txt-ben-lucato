# Bun

> Bun is a JavaScript and TypeScript runtime and toolkit for developers, combining a runtime, npm-compatible package manager, test runner, bundler, type checker, formatter and linter in one binary. The site provides docs, guides, API reference and release notes for building, testing and deploying…

- The site says bun install and bun test can be used in existing Node.js projects without switching the runtime to Bun.
- Bun runs on JavaScriptCore rather than V8, and the site says Node.js APIs and node_modules work as-is.

- [Plugins](https://bun.sh/docs/runtime/plugins.md): Documents Bun's plugin API, covering lifecycle hooks onStart, onResolve, onLoad and onBeforeParse, with usage examples and native plugin creation.
- [SQLite](https://bun.sh/docs/runtime/sqlite.md): Documentation for Bun's built-in bun:sqlite driver, covering database setup, statements, parameters, transactions, WAL mode and integer handling.
- [Compiler](https://bun.sh/docs/compiler.md): Explains how Bun compiles TypeScript or JavaScript into a single executable, compares the two compile modes, and links to detailed compiler docs.

## API

- [API Reference](https://bun.sh/reference.md): An index of Bun's API reference, listing Bun-specific modules, globals, and Node.js module implementations with short descriptions.
- [File System Router](https://bun.sh/docs/runtime/file-system-router.md): Documents Bun's FileSystemRouter API for resolving Next.js-style pages directory routes, with examples and a reference interface.
- [Markdown](https://bun.sh/docs/runtime/markdown.md): Documents Bun's built-in Markdown API with its html, render and react functions, parser options, callback signatures and React component overrides.
- [Semver](https://bun.sh/docs/runtime/semver.md): Documents the Bun.semver API, with functions to check whether a version satisfies a range and to compare versions.
- [Server](https://bun.sh/docs/runtime/http/server.md): Explains how to start and configure Bun.serve HTTP servers, including routes, ports, timeouts, HTTP/2 and HTTP/3, and server methods with code examples.
- [WebSockets](https://bun.sh/docs/runtime/http/websockets.md): Explains Bun's server and client WebSocket API, including handlers, pub/sub, compression, backpressure, timeouts and error handling.
- [SQL](https://bun.sh/docs/runtime/sql.md): Documentation for Bun's built-in SQL client, covering PostgreSQL, MySQL, MariaDB and SQLite connections, parameters, query results, transforms and fragments.
- [Redis](https://bun.sh/docs/runtime/redis.md): Documents Bun's native Redis client, covering commands, connection options, pub/sub, URL formats, error codes and limitations with code examples.
- [S3](https://bun.sh/docs/runtime/s3.md): API reference for Bun's S3 client, covering credentials, S3File methods, presigning URLs, S3-compatible endpoints and error codes.
- [Hashing](https://bun.sh/docs/runtime/hashing.md): Documents Bun.password, Bun.hash and Bun.CryptoHasher for password hashing, non-cryptographic hashing and incremental cryptographic digests, with supported algorithms and encodings.
- [FFI](https://bun.sh/docs/runtime/ffi.md): Explains Bun's bun:ffi module for calling native libraries from JavaScript, with usage examples, FFI types, strings, callbacks, pointers and memory management.
- [Cookies](https://bun.sh/docs/runtime/cookies.md): Documents Bun's native Cookie and CookieMap APIs, with methods, properties, constructors, examples and type definitions for working with HTTP cookies.
