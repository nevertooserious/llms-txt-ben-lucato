# Vitest

> Vitest is a Vite-native, Jest-compatible JavaScript and TypeScript testing framework. Its documentation is for developers writing unit, component, browser, type and benchmark tests, and covers configuration, the CLI, browser mode and the test APIs.

- Vitest does not require Vite; the site says it also works for non-Vite projects and backend code.
- The listed v4.vitest.dev page is a separate site for an older major version; vitest.dev holds the current documentation.

## Docs

- [Configuring Vitest](https://vitest.dev/config): Explains how to configure Vitest via vitest.config or vite.config files, with examples for defining options, merging configs, and environment variables.
- [Releases](https://vitest.dev/releases): Explains Vitest's release cycle, supported versions, semantic versioning edge cases, pre-releases, deprecations and experimental features.
- [Command Line Interface](https://vitest.dev/guide/cli): Reference for Vitest CLI commands such as run, watch, related, list and doctor, plus shell autocompletion setup and a long list of options.
- [Reporters](https://vitest.dev/guide/reporters): Documentation of Vitest's built-in test reporters, their configuration options, output locations, and how to combine them.

## API

- [Test](https://vitest.dev/api/test): Reference for the Vitest test function, its options, timeouts, retries, and modifiers like skip, only, each, and concurrent.
- [describe](https://vitest.dev/api/describe): Explains the describe function for grouping tests into suites, with its options, modifiers like skip, only, concurrent, and each variants.
- [Hooks](https://vitest.dev/api/hooks): Reference for Vitest lifecycle hooks such as beforeEach, afterEach, beforeAll, afterAll, aroundEach, aroundAll, onTestFinished and onTestFailed, with usage examples.
- [vitest-browser-react](https://vitest.dev/api/browser/react): Documents the vitest-browser-react package API for rendering React components in Vitest Browser Mode, including render, renderHook, options, and configuration.
- [vitest-browser-vue](https://vitest.dev/api/browser/vue): Documents the vitest-browser-vue package for rendering Vue components in Vitest Browser Mode, including render options, result methods, and configuration.
- [Context API](https://vitest.dev/api/browser/context): Documents the vitest/browser context module, covering userEvent, commands, page, cdp, server and utils exports available in browser tests.
- [Interactivity API](https://vitest.dev/api/browser/interactivity): Documents Vitest's browser userEvent methods for clicking, typing, hovering, keyboard, pointer and file upload interactions, with examples and provider notes.
- [Locators](https://vitest.dev/api/browser/locators): Reference for Vitest browser mode locator API, covering getBy methods, filters, chaining and interaction methods with examples.
- [Assertion API](https://vitest.dev/api/browser/assertions): Reference for Vitest's browser DOM assertion matchers, including retriable expect.element usage and individual matcher examples.
- [Commands](https://vitest.dev/api/browser/commands): Explains Vitest's built-in browser commands for files and CDP access, and how to write custom server-side commands with security checks.

## Guides

- [Getting Started](https://vitest.dev/guide): Getting started guide for Vitest covering installation, writing a first test, configuration, IDE integrations, and example projects.
- [Why Vitest](https://vitest.dev/guide/why): Explains why Vitest exists, how it relates to Vite and Jest, and its performance and compatibility advantages.
- [Features](https://vitest.dev/guide/features): Overview of Vitest's features including watch mode, snapshots, mocking, coverage, in-source testing, benchmarking, and sharding, with code examples.
- [Test Projects](https://vitest.dev/guide/projects): Explains how to define, filter, configure and debug multiple Vitest test projects within a single process, including config examples.
- [Browser Mode](https://vitest.dev/guide/browser): Explains running Vitest tests in a real browser: installation, configuration, providers, headless and UI options, examples, and limitations.
- [Test Context](https://vitest.dev/guide/test-context): Explains Vitest's test context and fixtures, including built-in context properties, extending tests with fixtures, scopes, injected values and overrides.
- [Test Run Lifecycle](https://vitest.dev/guide/lifecycle): Explains the phases of a Vitest test run, from configuration loading through global setup, test execution, hooks order, and teardown.
- [Snapshot](https://vitest.dev/guide/snapshot): Guide explaining Vitest snapshot testing: inline and file snapshots, updating, CI behavior, serializers, custom matchers, and differences from Jest.
- [Mocking](https://vitest.dev/guide/mocking): Guide to mocking in Vitest with links to mocking subguides and a cheat sheet of vi.fn, vi.mock and vi.spyOn examples.
- [Test Tags 4.1.0+](https://vitest.dev/guide/test-tags): Explains how to define, apply, and filter test tags in Vitest, including tag expression syntax and runtime tag matching.
- [Test Annotations](https://vitest.dev/guide/test-annotations): Explains how to attach custom messages and files to Vitest tests with annotate, and how each reporter displays them.
- [Extending Matchers](https://vitest.dev/guide/extending-matchers): Explains how to extend Vitest's expect matchers with custom matchers, TypeScript typings, matcher return values, and the matcher this context.
- [Testing Types](https://vitest.dev/guide/testing-types): Explains how to write type tests with expectTypeOf and assertType in Vitest, reading type errors, and running typechecking.
- [Benchmarking](https://vitest.dev/guide/benchmarking): Explains how to write, run, compare, store and assert Vitest benchmarks, plus stability and engine-specific performance considerations.
- [In-Source Testing](https://vitest.dev/guide/in-source): Explains how to write Vitest tests inside source files using import.meta.vitest, with config, production build exclusion for various bundlers, and TypeScript setup.
