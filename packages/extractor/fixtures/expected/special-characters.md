# Démarrage rapide

Installez Lumen avec `npm install lumen`, puis lancez `lumen dev`. Les fichiers nommés `_brouillon.md` sont ignorés.

Les options marquées \* sont obligatoires ; voir \[la référence\] pour la liste complète.

[Guide d’installation](https://lumen.example/fr/docs/installation) · Menu

## Étape 1 : créer le projet

1. Créez un dossier « mon-site ».
2. Ajoutez `index.md`.
